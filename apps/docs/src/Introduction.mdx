# My Design System

An accessible, **RTL-first** React component library.

- **Tokens** — CSS custom properties in two tiers (primitive → semantic), themed with `data-theme`.
- **Styling** — CSS Modules + logical properties only, so every component works in both `ltr` and `rtl`.
- **Accessibility** — every component ships with behavioural tests and an axe check.

Use the **Theme** and **Direction** menus in the toolbar above to switch between light/dark and LTR/RTL.
